# 智能更新策略使用说明

## 一、功能概述

为了避免频繁爬取触发厂商风控被封禁，实现了智能更新策略：

1. **分级更新**：不同数据类型按不同频率自动更新
2. **手动触发**：平台点击"更新数据"按钮立即更新（带冷却时间）
3. **增量更新**：只爬上次更新之后的新增数据，减少请求量80%以上
4. **请求限流**：每次请求间隔3-5秒（随机），避免规律性被识别
5. **失败重试**：失败后延迟30分钟重试，连续失败3次自动暂停
6. **智能降级**：检测到429错误时自动限流2小时

## 二、更新频率配置

| 数据类型 | 自动更新频率 | 更新时间 | 原因 |
|---------|------------|---------|------|
| 玩家账号 | 每天1次 | 凌晨2:00 | 注册用户不会频繁变化 |
| 充值明细 | 每6小时1次 | 2:00/8:00/14:00/20:00 | 充值数据相对频繁，但不需要实时 |
| 角色信息 | 每天1次 | 凌晨3:00 | 角色信息变化较慢 |

## 三、手动触发更新

### 3.1 触发方式
在"更新管理"页面，点击来源对应的"立即更新"按钮。

### 3.2 冷却时间
- 同一来源同一数据类型，**1小时内只能手动触发1次**
- 冷却时间未到时，按钮会显示剩余时间

### 3.3 数据范围
- 手动触发只爬**最近24小时的增量数据**
- 不会全量爬取历史数据，避免请求过多

## 四、操作界面说明

### 4.1 进入更新管理
打开爬虫平台（http://localhost:8000），点击顶部"更新管理"标签页。

### 4.2 定时任务状态
- 显示定时任务是否运行中
- 显示所有定时任务的触发规则和下次执行时间
- 可以启动/停止定时任务

### 4.3 来源更新状态表格
显示每个来源每个数据类型的更新状态：
- **来源ID**：来源编号
- **数据类型**：玩家账号/充值明细/角色信息
- **上次更新时间**：最后一次成功更新的时间
- **下次自动更新**：下次自动更新的预计时间
- **失败次数**：连续失败的次数
- **状态**：正常/失败N次/限流中/已暂停
- **手动冷却**：手动触发的冷却剩余时间
- **操作**：立即更新/恢复（暂停时显示）

## 五、API接口说明

### 5.1 手动触发更新
```
POST /api/crawler/update/manual
Content-Type: application/json

{
  "source_id": 1,
  "data_type": "player"
}
```

### 5.2 获取更新状态
```
GET /api/crawler/update/status?source_id=1
```

### 5.3 恢复暂停的来源
```
POST /api/crawler/update/resume
Content-Type: application/json

{
  "source_id": 1,
  "data_type": "player"
}
```

### 5.4 启动/停止定时任务
```
POST /api/crawler/scheduler/start
POST /api/crawler/scheduler/stop
```

## 六、常见问题

### 6.1 手动触发提示"冷却时间未到"
- 同一来源同一数据类型，1小时内只能手动触发1次
- 请等待冷却时间结束后再触发

### 6.2 状态显示"已暂停"
- 连续失败3次会自动暂停自动更新
- 点击"恢复"按钮可以恢复自动更新
- 建议先检查来源配置（账号密码、API配置）是否正确

### 6.3 状态显示"限流中"
- 检测到厂商返回429错误（请求过于频繁）
- 自动限流2小时，2小时后自动恢复
- 期间不要手动触发，避免加重限流

### 6.4 定时任务未启动
- 点击"启动定时任务"按钮启动
- 或重启爬虫服务，服务启动时会自动启动定时任务

## 七、与平台集成说明

### 7.1 平台点击"更新数据"按钮
平台后端调用爬虫服务的API：
```python
import requests

response = requests.post(
    "http://localhost:8000/api/crawler/update/manual",
    json={
        "source_id": source_id,
        "data_type": "player"
    }
)
result = response.json()
if result["success"]:
    print("更新任务已启动")
else:
    print("更新失败:", result["message"])
```
